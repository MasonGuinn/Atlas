# Computer Systems Curriculum

## Purpose

A comprehensive, foundational computer systems curriculum, built to be learned from notes rather than textbooks.

Go back to foundational skills and build ground-up, in dependency order, so every concept rests on the ones before it.

## How to Use This Curriculum

- Work through the levels and lessons in order. Do not skip ahead — later lessons assume earlier ones.
- Every lesson becomes a note built with the Standard Lesson Template, following the Learning Philosophy:
  - Learning Philosophy: deep understanding, long-term retention, and systems-level thinking over memorization.
  - Lesson Template: Why This Exists, Original Problem, Historical Context, Kurzgesagt Visualization, Story Version, Explain Like I'm 12, Mental Model, Technical Explanation, Expert Understanding / Edge Cases, Visual Diagram, Real Computer Example, Cybersecurity Connection, Common Misconceptions, Pause & Think, Connections Map, Permanent Takeaway.
- Link the concept word itself to its note, never a "Note X" label.
- Skip a template section for a lesson if it does not apply, rather than forcing it.
- Lesson 45, Networking Foundations, links to the existing Networking notes 00–18 in Notion — do not rebuild those notes. Lesson 46 builds systems programming on top of them.
- Where it fits, use hands-on work in the blackbox Ubuntu lab (for example: gdb for Lesson 23, C / systems programming for Level 4, sockets for Lesson 46).
- This artifact is the map. It can be added to or modified as the curriculum progresses.
