# Dashboard

Open this note on launch (Homepage plugin). Everything below is generated by Dataview — do not edit the tables by hand. Change a lesson's `status` in its frontmatter, and this page updates itself.

## Continue

Last-edited lessons, newest first. This is your resume point.

```dataview
TABLE status, domain, file.mtime AS "Last edited"
FROM "Learning"
WHERE type = "lesson"
SORT file.mtime DESC
LIMIT 10
```

## In progress

```dataview
TABLE domain, lesson
FROM "Learning"
WHERE type = "lesson" AND status = "in-progress"
SORT domain ASC, lesson ASC
```

## Next up per track

The first not-started lesson in each track. When you finish a lesson, set its status to `done` and the next one appears here automatically.

```dataview
TABLE lesson, file.link AS "Lesson"
FROM "Learning"
WHERE type = "lesson" AND status = "not-started"
SORT domain ASC, lesson ASC
LIMIT 20
```

## Progress

```dataview
TABLE length(rows) AS "Total", length(filter(rows, (r) => r.status = "done")) AS "Done", length(filter(rows, (r) => r.status = "in-progress")) AS "In progress"
FROM "Learning"
WHERE type = "lesson"
GROUP BY domain
```
